# Statecrafting

Tools for governed software work: authored intent, explicit authority and evidence you can inspect.

**[Explore statecraft.ing](https://statecraft.ing)** · [Specification catalog](https://statecraft.ing/registry) · [Get started](https://statecraft.ing/get-started)

- [spec-spine](https://github.com/statecrafting/spec-spine): specification compilation, authority and ownership.
- [Statecraft CLI](https://github.com/statecrafting/statecraft-cli): a local environment for governed work.
- [Rahi](https://github.com/statecrafting/rahi) and [Aicortex](https://github.com/statecrafting/aicortex): a Rust application chassis and governed persistent memory.
- [Rustev](https://github.com/statecrafting/rustev) and [Wire Witness](https://github.com/statecrafting/wire-witness): decision proposals and wire evidence, with explicit authority limits.

The public family also includes focused decision, trust, serialization and verification primitives. Each repository remains its own specification authority. The website shows declared lifecycle and implementation separately from verification and deployment qualification.

The Statecraft platform source remains private. Public code, a declared implementation and a deployed service are distinct claims.
